# Sistema de Monitoreo Maquinas Herramientas

## Descripción
Simulador interactivo para monitoreo de 4 máquinas herramienta con corriente trifásica.
Implementado con HTML5, CSS3 (Glassmorphism, Animaciones), JavaScript (POO, Async/Await),
Chart.js, SweetAlert2, Luxon

## Características
- Monitoreo en tiempo real de 4 máquinas
- Gráficos interactivos con Chart.js
- Sistema de alarmas por sobrecorriente
- Configuración de valores nominales 
- Intervalo de muestreo de datos configurable 
- Persistencia de datos con LocalStorage
- Diseño tecnológico responsive
- Historial de operaciones
- Exportación de datos en JSON

## Instalación
1. Clonar repositorio
2. Abrir index.html en navegador
3. Hacer clic en "Iniciar Simulador"
4. Interactuar con los botones para:
    * Ver todas las máquinas
    * Consultar una máquina específica
    * Configurar valores nominales
    * Exportar datos
5. Los datos se guardan automáticamente en LocalStorage
