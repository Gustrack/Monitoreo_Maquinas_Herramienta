Simulador de Monitoreo de Máquinas Herramientas

Descripción del Simulador

Este simulador monitorea 4 máquinas herramientas que operan con corriente trifásica. Para cada máquina, se simula la lectura de 3 corrientes trifásicas (I1, I2, I3), la tensión alterna (V) y se calcula la potencia activa (P).

El sistema permite realizar un muestreo general de todas las máquinas o consultar los datos de una máquina específica. Incluye sistema de alarma cuando las corrientes superan los valores nominales.
